Reproducible Run Commands

Follow this sequence to deploy, run, verify, and report a deterministic cluster workload. Use LAN addresses for local workers or WireGuard addresses for remote ones.

Environment assumptions

VariableExamplePurpose
MASTER_IP192.168.1.33 or 10.42.0.1Master address reachable by every worker.
WORKER_A_IP10.42.0.2Worker A address.
WORKER_B_IP10.42.0.3Worker B address.
REMOTE_PROJECT_DIR/appOptional common worker directory override.
MATRIX_SIZE600Deterministic square-matrix dimension.
MATRIX_SEED20260726Shared reproducibility seed.

Add convenient worker aliases to ~/.ssh/config:

Host workerA
    HostName 10.42.0.2
    User mobile
    IdentityFile ~/.ssh/dist_cluster_id

Host workerB
    HostName 10.42.0.3
    User mobile
    IdentityFile ~/.ssh/dist_cluster_id

1. Validate connectivity

ping -c 4 10.42.0.2
ping -c 4 10.42.0.3

ssh workerA echo "workerA reachable"
ssh workerB echo "workerB reachable"

Configure key authentication first if either SSH command prompts for a password. See the SSH hardening guide.

2. Deploy worker dependencies

bash deploy_cluster.sh

Linux workers default to /app; macOS workers default to ~/dist_cluster. Export REMOTE_PROJECT_DIR to override both.

3. Launch the cluster

bash run_cluster.sh

The orchestrator will:

  1. Profile every worker route and choose a receive size.
  2. Run SSH and source preflight checks.
  3. Launch all worker ranks and rank 0.
  4. Distribute deterministic matrix rows using framed JSON.
  5. Assemble and verify the complete result.
  6. Record measured telemetry and generate the report.

4. Run a smaller smoke test

Use a 32×32 matrix to exercise transport and computation quickly:

REMOTE_DIR="/app"

ssh workerA "cd $REMOTE_DIR && \
  MASTER_ADDR=10.42.0.1 MASTER_PORT=8080 WORLD_SIZE=3 RANK=1 \
  MATRIX_SIZE=32 python3 train_dist.py" &

ssh workerB "cd $REMOTE_DIR && \
  MASTER_ADDR=10.42.0.1 MASTER_PORT=8080 WORLD_SIZE=3 RANK=2 \
  MATRIX_SIZE=32 python3 train_dist.py" &

MASTER_ADDR=10.42.0.1 MASTER_PORT=8080 WORLD_SIZE=3 RANK=0 \
  MATRIX_SIZE=32 python3 src/train_dist.py

wait

Rank 0 should produce matrix_output.csv and run_metrics.json. Workers report assigned row counts and compute times.

5. Regenerate artifacts

python3 verify_output.py
python3 log_metrics.py run_metrics.json
python3 generate_report.py
ArtifactContents
matrix_output.csvAssembled distributed matrix product.
run_metrics.jsonMeasured network, compute, and wall-clock durations.
verification_result.jsonGround-truth pass/fail and error statistics.
cluster_performance.csvHistorical measured runs.
FINAL_PROJECT_SUMMARY.mdLatest measured report.

Full sequence

ping -c 4 10.42.0.2 && ping -c 4 10.42.0.3
ssh workerA echo "OK" && ssh workerB echo "OK"
bash deploy_cluster.sh
bash run_cluster.sh
cat FINAL_PROJECT_SUMMARY.md

Troubleshooting

SymptomLikely causeAction
SSH timeoutLAN or WireGuard path unavailable.Confirm routing and reconnect WireGuard.
Worker cannot reach rank 0Master address mismatch.Set MASTER_IP; use ALLOW_MASTER_WILDCARD_BIND=1 only for a firewalled mixed-path run.
Public-key denialWorker lacks the orchestrator key.Follow SSH hardening.
Worker exits immediatelySource or dependency missing.Run bash deploy_cluster.sh again.
High latency or stallDegraded route.Use the latency guide.
Report generation failsMeasured metrics missing.Confirm run_metrics.json exists and rerun the post-run commands.
